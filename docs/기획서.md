# 액션 슈팅 게임 기획서

- **목적:** 기말 과제 게임 기획서
- **작성자:** 현민규

## 게임 제목: ONE SHOT ONE KILL

- **장르:** 2D 횡스크롤 핵앤슬래시 액션 슈팅

### 게임 소개

마피아 조직이 활개 치던 1920~30년대 미국의 가상 도시를 배경으로 한다. 플레이어는 마피아 조직원들을 물리치며 도시를 장악한 보스에게 다가간다.

### 핵심 재미

핵앤슬래시 장르의 빠른 전투와 다수의 적을 쓸어버리는 쾌감이 중심이다. 플레이어는 여러 무기와 스킬을 조합해 적을 연속으로 처치하고, 적의 공격을 피하면서 콤보를 이어 간다. 탄약 제한을 두지 않아 전투가 끊기지 않도록 한다.

### 플레이 방식

1. 횡스크롤 스테이지를 이동하며 마피아 조직원과 싸운다.
2. 기본 공격과 스킬을 조합해 여러 적을 빠르게 처치한다.
3. 적의 공격을 피하고 콤보를 이어 간다.
4. 스테이지 마지막에 등장하는 보스를 물리친다.

### 스테이지

- **1스테이지: 재즈 클럽**  
  마피아가 운영하는 재즈 클럽에 잠입해 조직원들과 싸운다. 홀과 주방을 지나 클럽 내부를 돌파하고, 마지막에는 클럽을 지키는 중간 보스와 대결한다.
- **이후 스테이지:** 구상 중

### 주요 요소

- **무기:** 권총, 산탄총, 토미건 등 시대에 어울리는 총기를 사용한다. 탄약 제한은 없다.
- **스킬:** 여러 적을 공격하는 범위 기술과 강한 적을 상대하는 기술을 사용한다.
- **적과 보스:** 일반 조직원, 경호원, 원거리 공격 적이 등장한다. 스테이지 마지막에는 강력한 적이 기다린다.
- **성장:** 적을 처치해 경험치를 얻고 공격력이나 체력을 강화한다.

### 기타

- **시대 배경:** 마피아가 활발히 활동하던 1920~30년대 미국
- **분위기:** 느와르풍의 어두운 도시와 재즈 음악
- **이후 스테이지 및 세부 설정:** 구상 중
