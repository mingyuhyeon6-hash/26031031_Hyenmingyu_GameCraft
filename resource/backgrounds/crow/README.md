# 까마귀 비행 스프라이트

느와르 도시 배경에 어울리는 검정·청회색의 8비트풍 까마귀입니다.

- 파일: `crow_fly.png` (투명 배경 PNG)
- 배치: 2열 × 2행, 총 4프레임
- 실제 파일 크기: 1254 × 1254px, 한 칸: 627 × 627px
- 게임 표시 권장 크기: 한 칸을 48 × 48px 또는 64 × 64px로 표시
- 재생 순서: 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 → 반복
- 권장 속도: 초당 8프레임 (한 장당 0.125초)
- 방향: 오른쪽. 왼쪽으로 날 때는 좌우 반전합니다.
- 확대·축소 시 NearestNeighbor를 사용하면 도트가 선명하게 보입니다.
- 각 칸을 같은 크기로 잘라 사용합니다. 이미지 전체를 한 마리로 그리지 않습니다.

제작: OpenAI 내장 image_gen 도구. 생성 프롬프트는 `prompt.txt`, 최종 도트 단순화 지시는 `prompt-refinement.txt`에 보관했습니다. 생성 이미지이므로 정확한 32 × 32 픽셀 원본은 아니며, 큰 도트 형태로 표현한 8비트풍 리소스입니다.

현재는 리소스 제작 단계이며, 게임 실행 코드에는 아직 연결하지 않았습니다.
